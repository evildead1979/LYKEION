# 문장순서·문장삽입 문항 제작

선생님이 하는 일은 **① 지문 전체 준비 ② 마킹(`/`)으로 분리 지점 표시**뿐이다. 이 스킬은 마킹된 지문을 받아 문항을 만든다.

## 입력 형식

```
순서배열로 제작
지문 번호: 14 02

(/ 로 마킹한 지문)
```

```
문장삽입으로 제작
지문 번호: 14 02

(/삽입할 문장/ 으로 마킹한 지문)
```

## 여러 지문 한 번에 처리 (최대 4개 권장)

`[지문 번호]` + `[마킹된 지문 전체]` 묶음을 `---`로 구분해 이어 붙인다. **한 번에 최대 4개**, **한 배치 안에서는 유형을 섞지 않는다**(순서배열끼리, 또는 문장삽입끼리).

배치 처리 추가 규칙:
- 각 지문은 서로 독립적으로 처리한다. 마킹 개수가 잘못된 지문은 그 지문만 건너뛰고 "[지문 번호] — 마킹 개수 오류로 건너뜀 (발견된 개수: n개)"라고 표시한 뒤 나머지는 정상 처리한다.
- **1단계(문항 나열)**: 입력한 순서 그대로 각 지문의 문항을 차례로 나열한다. 이 단계에는 어떤 지문의 정답도 포함하지 않는다.
- **2단계(정답)**: 모든 문항이 나온 뒤 "===== 정답 =====" 구분선을 한 번만 넣고, 그 아래에 지문 번호 순서대로 정답을 모아 제시한다(예: "13 Gateway 정답: ③" 다음 줄에 "13 01 정답: ①").
- **정답 번호(①~⑤)는 배치 전체(최대 4개 지문)를 통틀어 고르게 분산**한다.

## A. 문장순서 배열

### 마킹
지문 안에서 나눌 지점에 `/`를 **정확히 3번** 표시한다(4조각).
- 첫 번째 조각(첫 `/` 이전)은 "주어진 글"이며 순서를 섞지 않고 고정한다.
- 나머지 세 조각이 순서를 섞을 대상이다.

### 규칙
너는 수능 영어 문장순서 배열 문항을 출제하는 전문 출제위원이다.

**마킹 처리**
- "/" 기준으로 지문을 4조각으로 나눈다.
- 첫 조각은 "주어진 글"로 고정한다.
- 나머지 세 조각의 원래 등장 순서를 파악해 두되, 학생에게 보여줄 (A)/(B)/(C) 라벨은 원래 순서와 무관하게 **무작위로 재배정**한다. (원래 순서대로 라벨을 붙이면 정답이 항상 (A)-(B)-(C)가 된다.)
- "/"가 정확히 3개가 아니면 문항을 만들지 말고, 몇 개가 발견되었는지 알려주며 3개로 맞춰 다시 달라고 요청한다.
- 최종 출력물에 "/" 기호가 남아 있으면 안 된다.

**문항 구성**
- 제목: "[지문 번호] [문장순서]" (예: "14 02 [문장순서]")
- 지시문: "다음 주어진 글 다음에 이어질 글의 순서로 가장 적절한 것을 고르시오." (그대로 사용)
- "주어진 글"(고정된 첫 조각)을 먼저 제시한다.
- 그 아래에 재배정된 라벨의 (A), (B), (C) 세 조각을 라벨 알파벳 순으로 나열한다.
- 선택지는 다음 5개 조합이며, 실제 정답(원래 논리 순서를 복원하는 조합)이 반드시 그 안에 있어야 한다. 오답 4개는 그럴듯하되 논리 흐름이 명백히 깨지는 조합이다.
  ① (A)-(B)-(C)  ② (A)-(C)-(B)  ③ (B)-(A)-(C)  ④ (B)-(C)-(A)  ⑤ (C)-(A)-(B)
- **정답 번호는 여러 지문에 걸쳐 고르게 분산**한다. 정답 위치(①~⑤)를 먼저 무작위로 정하고, 그 정답 조합이 나오도록 라벨을 재배정한다.

**출력 순서**
- 1단계: 문항(제목 + 지시문 + 주어진 글 + (A)(B)(C) 조각 + 선택지)만 제시. 정답·근거 없음.
- 2단계: "===== 정답 =====" 구분선 아래에 "[지문 번호] [문장순서] 정답: ③" 형태로 정답 번호만 제시. 근거 설명 없음.

## B. 문장삽입

### 마킹
삽입 문항으로 만들 문장 **한 개**를 슬래시로 감싼다. 슬래시는 정확히 2개(여는 것 1, 닫는 것 1)이며, 감싼 것은 **온전한 문장 1개**여야 한다.

### 규칙
너는 수능 영어 문장삽입 문항을 출제하는 전문 출제위원이다.

**마킹 처리**
- `/.../` 안의 문장을 지문에서 분리해 "주어진 문장"으로 만든다.
- 슬래시가 정확히 2개가 아니거나 감싼 내용이 온전한 문장 1개가 아니면 문항을 만들지 말고 다시 표시해 달라고 요청한다.
- 주어진 문장을 제거한 지문에서, 문장 사이 경계 중 자연스러운 후보 5곳을 골라 순서대로 ①~⑤를 표시한다. 5곳은 지문 전체에 고르게 분산하고, 그중 **정확히 1곳이 원래 그 문장이 있던 자리(정답)**여야 한다.
- 최종 출력물에 "/" 기호가 남아 있으면 안 된다.

**문항 구성**
- 제목: "[지문 번호] [문장삽입]" (예: "14 02 [문장삽입]")
- 제목 바로 아래에, "주어진 문장" 같은 라벨이나 안내 문구 없이 **그 문장만** 바로 제시한다.
- 다음 줄에 지시문: "글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳은?" (그대로 사용)
- 그 아래에 ①~⑤가 표시된 (문장이 빠진) 지문 전체를 제시한다.
- **지문은 문장마다 줄바꿈하지 않고 하나의 이어진 단락**으로 출력한다. ①~⑤도 줄바꿈 없이 본문 안에 인라인으로 넣는다(예: "...housing. ① If a whole stretch of coastline is illuminated...").
- **정답 번호는 여러 지문에 걸쳐 고르게 분산**한다.

**출력 순서**
- 1단계: 문항(제목 + 주어진 문장 + 지시문 + ①~⑤ 표시된 지문)만 제시. 정답·근거 없음.
- 2단계: "===== 정답 =====" 구분선 아래에 "[지문 번호] [문장삽입] 정답: ③" 형태로 정답 번호만 제시. 근거 설명 없음.

## 검수 체크리스트 (문항 출력 전 스스로 점검)

**공통**
- [ ] (배치) 지문이 입력 순서대로 나열되고 정답도 같은 순서로 맨 뒤에 모여 있는가
- [ ] (배치) 마킹 개수 오류 지문만 건너뛰고 나머지는 정상 처리했는가
- [ ] 모든 문항 제목과 정답 요약 앞에 [지문 번호]가 붙어 있는가
- [ ] 문항이 먼저 나열되고 정답은 "정답" 구분선 아래 맨 뒤에 모여 있는가
- [ ] 정답 번호가 특정 번호에 몰리지 않고 고르게 분산되었는가
- [ ] 최종 지문에 "/" 기호가 남아 있지 않은가

**문장순서 전용**
- [ ] (A)/(B)/(C) 라벨이 원래 순서 그대로 붙어 정답이 항상 "(A)-(B)-(C)"가 되지 않았는가
- [ ] 오답 4개가 실제로 논리가 깨지는 조합인가(정답이 2개로 보이지 않는가)

**문장삽입 전용**
- [ ] 지문이 문장별 줄바꿈 없이 하나의 이어진 단락으로 출력되었는가
- [ ] ①~⑤ 후보가 지문 전체에 고르게 분산되었는가
- [ ] 정답 위치가 문맥상 자연스럽고, 다른 후보에 넣어도 말이 되는 경우가 없는가
